# MepilGlobal Secure Guard V1.0
## 🚀 What it does
A proprietary inventory management system that uses barcode scanning to automate equipment tracking and generate real-time 
Excel reports for check-ins and check-outs.
## Why it’s useful
Manual tracking often leads to asset loss, ghost inventory, and zero accountability. This project solves these issues by:
* **Eliminating Human Error**: Barcode scanning ensures the right item is logged every time.
* **Driving Accountability**: Each check-in/out is timestamped and tied to a specific user, reducing theft and damage.
* **Ready-to-Use Data**: Generating instant Excel reports means managers have audit-ready data without manual data entry.
* **Versatile Industry Fit**: Designed for use in Construction, Healthcare, Education, and Media Production where equipment mobility is high.

## 🛠️ Project Overview & Tech Stack
This repository contains the complete source code for a robust **Python-based** tracking solution, featuring a high-speed scanning engine and an automated data export pipeline.
*   **Core Language: ** Python 3.x
*   **Scanning Engine: ** [ OpenCV / PyZbar] (High-speed barcode and QR code recognition)
  

*   **Key Features: ** 
    *   **Instant Recognition**: High-accuracy barcode scanning via camera or connected hardware.
    *   **Precision Logging**: Automated timestamping (Date & Time) for every check-in and check-out.
    *   **One-Click Reporting**: Dynamic .xlsx export functionality for instant audit-ready reporting.
