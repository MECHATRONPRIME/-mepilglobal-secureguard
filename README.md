# MepilGlobal SecureGuard V1.0
### 🚀 Automated Inventory & Equipment Tracking System

[![Watch the Demo](https://shields.io)](https://youtu.be)

Developed by **Francis Osademe from Nigeria**, **MepilGlobal SecureGuard** is a robust inventory application used to track equipment and items in workshops or high-mobility environments. Using a standard PC webcam, the system scans barcodes attached to equipment to automate check-ins and check-outs.

---

## 🛠️ What it Does
A professional inventory management system designed to eliminate ghost inventory and ensure total accountability through automated data capture.

*   **Instant Recognition**: High-speed scanning engine for barcodes and QR codes via a personal computer webcam.
*   **Precision Logging**: Captures the exact **Date, Time, and Status** of every item automatically.
*   **One-Click Reporting**: Generates real-time, audit-ready Excel (.xlsx) reports to replace manual data entry.

## 💡 Why it’s Useful
Manual tracking often leads to asset loss, theft, and human error. This project solves these issues by:
*   **Eliminating Human Error**: Barcode scanning ensures the right item is logged every time.
*   **Driving Accountability**: Every scan is timestamped, reducing damage and increasing user responsibility.
*   **Ready-to-Use Data**: Provides managers with instant data export for reporting and audits.
*   **Versatile Industry Fit**: Optimized for Construction, Healthcare, Education, and Media Production.

## ⚙️ Technical Overview
This documentation serves as a **Portfolio Demonstration** and **Proof-of-Creation**, confirming the development of these automation and data management protocols.
*   **Core Language:** Python 3.x
*   **Vision Engine:** OpenCV / PyZbar (High-speed recognition)
*   **Data Pipeline:** Automated Excel export pipeline.
